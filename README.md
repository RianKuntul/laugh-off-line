One funny line, at most 200 characters: ask the smart speaker for
something relaxing, and it reads your bank balance out loud — in a
spa voice.

## Run

```sh
node main.ts
```

Writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to
`/output/entry.txt`), after self-validating the gate: exactly one line,
1–200 characters.
